# 비바샘 원격연수 납품 규격

근거는 비상교육 제작 가이드, 6차시 예시 영상 실측, 검수서다. 가이드와 실측이 다른 곳은 둘 다 적었다.
검수에서 걸린 것은 [검수-공통지적.md](검수-공통지적.md) 에 따로 모았다.

## 제출물

차시당 영상 두 개. 002 는 퀴즈 페이지라 영상이 없다.

| 파일 | 내용 | 음성 | 길이 |
|---|---|---|---|
| `NN_YYYYMMDD_001.mp4` | 인트로 → 오프닝 → 표지 → 학습 목표 → 학습 내용 → 본연수 → 마무리 | 있음 | 20~25분 |
| `NN_YYYYMMDD_003.mp4` | 돌아보기 ×3 → 참고 문헌 → 차시 예고 (엔딩 표지 없음) | 없음 (BGM만) | 40초 안팎 |

- 차시번호는 두 자리(`06` ○ / `6` ✕). 날짜는 **내보내 제출하는 날**. 가이드 예시 날짜를 베끼지 않는다
- 영상 규격 1920×1080 · 30fps · H.264 · MP4

## 001 구성 (6차시 예시 실측)

```
0.0 ─ 8.0     비바샘 인트로 (제공 파일, 8.008초. 캡컷에 놓으면 8.033초)
8.0 ─ 80.3    오프닝 · 선생님 얼굴 · 말자막      (가이드 30~45초, 예시 72초)
80.3 ─ 83.8   표지 (과정명 / 차시 / 차시명 / 교사 ○○○)
83.8 ─ 131    학습 목표 → 학습 내용            (BGM, 2권은 읽지 않는다)
131 ─         간지 → 본학습 …
끝 24초       표지 재등장 · 마무리 멘트
```

- 화면 전환: 인트로 ↔ 오프닝 ↔ 본연수에 「B 페이드」(0.467초). 슬라이드끼리는 넣지 않는다
- 오프닝 배경은 표지 슬라이드가 아니다. 종이 질감 배경에 과정명 두 줄과 오른쪽 아래 강사명만 있는 전용 화면이다(팀마다 받는다)

## 003 구성

```
0 ─ 27     학습 내용 돌아보기 ×3 (각 9초, 항목마다 하위 글 두세 줄)
27 ─ 33    참고 문헌
33 ─ 38    차시 예고 (다음 차시명)          ← 여기서 끝낸다
```

- **차시 예고로 끝낸다. 엔딩 표지·간지를 붙이지 않는다**(검수에서 삭제 요청). 가이드는 엔딩 표지를 적었지만 검수와 예시를 따른다
- **그림은 캔바(교안 원본)에서 PNG 로 받는다.** 파워포인트로 뽑으면 교안 글꼴(네모고딕 등)이 없는 PC 에서 다른 글꼴로 바뀐다(「폰트가 깨져 있다」 지적)
- 참고 문헌은 견본 형식. 책은 「제목 (출판사, 연도)」, 그 밖은 「저자·기관, 제목」. 책 제목은 실제 책과 띄어쓰기까지 같게.
  **실제로 있는지 찾아본다.** SNS 게시물 하나를 문서처럼 적지 않는다
- BGM 은 크기를 맞춘 파일(−21.4 LUFS)을 깔고 끝 2.5초 페이드아웃. 003 이 001 보다 크게 들리지 않게 한다

## 말자막

**오프닝(선생님 얼굴이 보이는 화면)에만 단다. 본연수에는 달지 않는다.** 검수에서 가장 많이 걸린 항목이다.
실습 구간에 꼭 필요한 안내는 「지도 Tip」 한 줄로 띄울 수 있다(말을 받아 적은 자막이 아니다).

### 캡컷 설정 (이것을 쓴다)

| 항목 | 캡컷 값 | 드래프트 값 |
|---|---|---|
| 글꼴 | 고딕체 (캡컷 글꼴 목록) | `font_resource_id` 6808056385679397389 (DoHyeon-Regular) |
| 글꼴 크기 | 6 | `font_size` 6 |
| 색상 | 흰색 | 글자 채움 [1, 1, 1] |
| 위치 | Y −810 | `transform.y` −0.75 |
| 배경 | 검정 · 불투명도 70 · 높이 0 | `background_alpha` 0.70 · `background_height` 0 |

도구는 이 값을 짓지 않고 `templates/말자막_본.json`(사람이 캡컷에서 만든 한 줄)을 복제한다. 줄 이름은 「인트로 말자막」.

- 한 줄 25자 안, 두 줄까지. **의미 단위로 직접 끊는다.** 길면 같은 화면에서 두 번에 나눈다
- 문장이면 마침표, 명사로 끝나면 찍지 않는다. 문장을 중간에서 끊은 채로 두지 않는다
- 말한 그대로 적는다. 슬라이드와 띄어쓰기를 같게 한다. 위치는 끝까지 고정
- 재생바와 떨어뜨린다(상자 아래끝이 화면 바닥에서 86px 넘게 위)
- 참고(가이드 표): 나눔스퀘어라운드 ExtraBold · 글자 48px · 상자 높이 77px · 불투명 70~75%

## 오프닝

- 길이 30~70초. 인사 → 과정명 → 몇 번째 시간 → 지난 시간 → 오늘 할 것 → 「그럼 시작하겠습니다」
- 차시 번호를 말로 하지 않는다(「여섯 번째 시간입니다」는 괜찮다. 「○○ 여섯 번째 시간」처럼 차시명을 붙이지 않는다)
- 배치(1080p): 머리 꼭대기 y 약 400, 머리 가운데 x 960, 머리 폭 약 275px. 과정명 아랫줄과 머리 사이에 여유, 어깨가 강사명에 닿지 않게
- 크로마키 천이 없어도 된다. `tools/오프닝.py 합성` 이 AI 매팅으로 사람만 오린다. 파란 천을 썼어도 같은 도구를 쓴다
- 촬영 요령은 [촬영-안내.md](촬영-안내.md)

## 오디오

**오포닉(Auphonic) Voice Cleaner → Remove Breath** 로 보정한다.

1. 편집을 다 마친 뒤 캡컷에서 인트로 소리를 끄고 오디오만 내보낸다
2. 오포닉에서 보정하고 **앞뒤 워터마크 음성을 잘라 낸다**(못 자르면 영상 처음·끝에 안내 음성이 나온다)
3. `tools/소리.py 목소리넣기` 가 보정본을 따로 줄에 깔고 시각을 맞춘 뒤 **영상 클립 소리를 끈다**
   - 끄지 않으면 보정 목소리와 원래 녹음이 1~2ms 차이로 겹친다. 메아리로 안 들리고 음색만 조금 바뀌어 귀로도 검수로도 못 찾는다
   - 인트로 클립 소리는 끄지 않는다
- 라우드니스 기준은 가이드에 없다. 예시 001 −21.5 LUFS, 제공 인트로 −21.3. 오포닉 보정본은 −16 안팎으로 나온다. 인트로(음악)보다 목소리가 큰 것은 괜찮다
- 오프닝 목소리도 같은 보정본에 들어가야 한다. 오프닝만 날소리면 본편보다 10 LU 넘게 작다

## 촬영 원본

파트를 나눠 찍으면 이름을 `차시_파트번호_파트명_테이크.mp4`(예: `06_03_파트1_T1.mp4`)로 짓고 쓸 파일 끝에 `_OK` 를 붙인다.
파트번호는 영상에 들어갈 순서다. 테이크 앞의 육성 슬레이트(「성명, 몇 차시, 테이크 1」)는 lecture-cut 이 찾아 지운다.
원본은 옮기지 않을 로컬 폴더에 둔다. 다운로드·클라우드 폴더에 두면 나중에 프로젝트의 소재가 끊긴다.

## 편집 순서 (가이드)

```
원본(파트 순) → NG·중복 컷 → 인트로 → 파트 사이 전환 → 오프닝 말자막 → 블러 → 1차 내보내기
→ 음성 추출 · 오포닉 보정 · 다시 넣기 → 최종 내보내기
```

블러: 작업표시줄, 캘린더 날짜, 북마크, 이메일·실명·개인정보, 화면에 보이는 키·토큰.

## 말할 때와 화면 글

| ✕ | ○ |
|---|---|
| 앞 차시에서 / 7차시에서 | 지난 시간에 / 오늘 함께 |
| 아이 · 학생들 | 학생 (교사 발화 인용은 예외) |
| SEL (첫 등장) | 사회정서교육(SEL) |
| 시청해 주셔서 | 함께해 주셔서 |

- 버튼·메뉴 이름은 [대괄호]. 강조할 말은 '작은따옴표'. 문장 안 가운뎃점(·)은 「및」
- 띄어쓰기: 우리 반, 계정 정보, 학생 목록, 확장 프로그램(띄움) · 웹앱(붙임)
- 이미지 출처는 「출처: ChatGPT 생성 이미지」「출처: Google Gemini 생성 이미지」로 통일

## 효과

| 효과 | 값 |
|---|---|
| 교안 애니메이션 | 나타내기(밝기 변화) 한 종류 · 0.5초 · 클릭할 때 · 장당 3~6단계 |
| 장면 전환 | 「B 페이드」 0.467초. 인트로 ↔ 오프닝 ↔ 본연수, 슬라이드 ↔ 실습 |
| 강조 상자 | 내레이션에 맞춰 띄운다. 처음부터 떠 있으면 지적 |
| 작은 글씨 확대 | 코드·설정·시트 화면. 최대 2배 |
| 한 화면 50초 넘게 그대로 | 나타내기·강조·확대·나누기 중 하나를 넣는다 |

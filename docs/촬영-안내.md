# 오프닝 촬영 안내

오프닝은 인트로(8초) 바로 뒤에 선생님 얼굴이 나오는 30~70초 구간이다. 이 팩이 사람만 오려 팀 배경 위에 올린다.

## 찍기

- **휴대폰 세로로 찍어도 된다.** 4K 세로 영상에서 확인했다. 가로로 찍어도 된다
- **파란 천(크로마키)이 없어도 된다.** 방 벽이나 커튼 앞도 된다. 다만 옷과 배경 색이 너무 비슷하면(흰 셔츠 + 흰 벽) 가장자리가 흐려질 수 있다
- 가슴 위부터 머리 위 여유까지 들어오게. 어깨 아래는 잘려도 된다(화면 밖으로 나간다)
- 얼굴이 밝게, 뒤에서 빛이 들어오지 않게. 카메라는 눈높이
- 녹화를 켜고 3초 쉬었다가 시작, 끝나고 3초 쉬었다가 끈다

## 말하기

- 틀리면 **그 문장 처음부터** 다시 말한다. 도구가 문장마다 마지막 온전한 테이크를 고른다
- 문장 사이에 1초쯤 쉰다. 자르기 쉽다
- 차시 번호를 말하지 않는다. 「열두 번째 시간입니다」처럼 회차는 괜찮다
- 「아이」 대신 「학생」. 강의 내용과 다른 기능 이름을 말하지 않는다(오프닝 말은 자막으로 그대로 나간다)
- 짜임: 인사 → 과정명 → 몇 번째 시간 → 지난 시간 → 오늘 할 것 → 「그럼 시작하겠습니다」

## 넘기기

촬영본 원본 파일(MOV·MP4)을 그대로 준다. 다시 내보내거나 줄이지 않는다.
팀 오프닝 배경 그림(과정명·강사명이 들어간 1920×1080 PNG)도 함께 준다.
